# KB Sync Portfolio

Run only `python .claude/skills/kb-sync-portfolio/scripts/sync_portfolio_pages.py`.

Permit only `--classification <path>` (defaults to
`exports/portfolio-classification/portfolio-classification.json`) and
`--check` (dry-run: reports whether pages would change, writes nothing, exits
non-zero if out of date). Do not run arbitrary SQL or Python, do not read
DuckDB directly, and do not hand-edit `portfolio/holdings.md` or
`portfolio/portfolio-overview.md` -- they are regenerated by this script only
(see [page-contract.md](references/page-contract.md) for their exact
layout). The classification JSON is the sole source of truth for holdings
data; do not fabricate or adjust figures.

On a successful non-check run, the script also rebuilds `portfolio/index.md`
and the main `Knowledge-Base/index.md` recently-updated table, and appends a
row to `logs/update-log.md` if anything changed.
