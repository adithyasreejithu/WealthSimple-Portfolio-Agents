# Research Note Template

For dated notes filed under `earnings/earnings-notes/`, `dividends/`, or
`market-research/*/`. Name files `<YYYY-MM-DD>-<slug>.md`. Set `type` to the
matching note type (`earnings-note`, `dividend-note`, `sector-note`,
`macro-note`, `sentiment-note`, `options-note`, or generic `research-note`).

# Title

## Facts

What is verifiably true, with sources.

## Analysis

Interpretation — clearly separated from facts. Label assumptions, estimates,
and opinions as such.

## Implications

needs a thesis update.
