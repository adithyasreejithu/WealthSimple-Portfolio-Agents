# Theses

Theses are not separate documents — the full thesis lives on each canonical
stock page in [../stocks/](../stocks/index.md). The folders below are
regenerated *views* grouped by the stock page's `status` front matter, so
pages never move and links never break.

- [Active](active/index.md) — currently held with a live thesis.
- [Watchlist](watchlist/index.md) — candidates under consideration.
- [Closed](closed/index.md) — positions exited; thesis preserved for the record.
- [Rejected](rejected/index.md) — researched and passed on, with reasoning.

Pages with status `research` (work in progress) appear only in the stocks index.
